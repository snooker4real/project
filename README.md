# project

**Stack** : React, Vite, Tailwind CSS, TypeScript

## Démarrage

```bash
npm install   # installer les dépendances
npm run dev   # serveur de développement
npm run build   # construire
npm run lint   # lint
npm run preview   # prévisualiser le build
```
